## About

TerraForge is a Minecraft-inspired game engine built from scratch
with C# and OpenGL.

The project is primarily focused on learning graphics programming,
game engine architecture, and low-level rendering.

## Features

- OpenGL rendering
- 3D camera
- Texture loading
- Shader system
- Voxel-based world
- Player movement

- ## Tech Stack

- **Language:** C#
- **Framework:** .NET 10
- **Graphics:** OpenGL
- **OpenGL bindings:** OpenTK
